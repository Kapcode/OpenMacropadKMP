# Data Tracking Transparency

This document outlines exactly what data is tracked by MacroKapKMP, why it is tracked, and how you can control it.

## 🛡️ Privacy First: Opt-in Only
Tracking is **DISABLED** by default. No analytics data is collected unless you explicitly enable it in the **Settings** menu.

## 📊 What We Track

When analytics are enabled, the following information is collected anonymously:

### Device Specifications (User Properties)
We collect basic hardware information to understand the performance of devices running the app and to optimize the experience.
- **Device Model & Manufacturer**: (e.g., Pixel 9 Pro, Samsung S24)
- **Android Version**: (e.g., Android 14)
- **CPU ABI**: Supported processor architectures.
- **Hardware & Board**: Low-level hardware identifiers.
- **Total RAM**: Amount of system memory (in GB).
- **Pro Status**: Whether you are a Free user, a Local Pro user (purchased), or a Server Pro user (temporary access).

### Usage Data (Events)
We track how users interact with the app to improve the UI and prioritize features.
- **Screens Accessed**: Which parts of the app are used (Server List, Dashboard, Marketplace, Settings).
- **Server Connections**: When a successful connection is made to a Macropad server (includes server name and connection security status).

## 🚫 What We DO NOT Track
- **Keystrokes**: We NEVER track what you type or what macros you execute.
- **Passwords/Tokens**: Sensitive credentials never leave your device except to the server you connect to.
- **Location**: We do not collect GPS or precise location data.
- **Personal Identity**: No names, emails, or phone numbers are collected by our analytics.

## 🛠️ How to Disable Tracking
1. Open the **Settings** menu in the app.
2. Toggle off the **Enable Analytics** setting.
3. Once disabled, the app will stop collecting and sending any analytics data immediately.
